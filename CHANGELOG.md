# Изменения

## Обновление интерфейса VPN

- Новая верхняя шапка с названием из конфигурации, балансом и профилем.
- Горизонтальная навигация на компьютере и сохранённая мобильная навигация.
- Главная с инструкцией «Выбрать тариф → оплатить → подключить устройство».
- Подключить VPN открывает существующий выбор тарифа.
- Страницы баланса, истории операций и текущих уведомлений.
- Страницы услуг, профиля, входа и поддержки объединены стилями Pages.css.
- Удалён интерфейс HWID из услуг; серверные HWID маршруты не изменяются.
- Документация установки, обновления GitHub, публикации GHCR и ограничений API.

## Важные границы

Сборка клиента не устанавливает серверные методы AccountProfile. Их пакет поставлялся отдельно. Встроенная история операций открывает существующие таблицы, а уведомления показывают состояния услуг, не полный исторический журнал. Работоспособность платежей и OAuth зависит от настроенного сервера SHM.

## Упрощение профиля и мобильная адаптация

Удалены Готовность профиля и экспериментальная панель сессий. Дополнительный API профиля больше не требуется. Обновлены формы входа, история пополнений, карточки заказа и поддержка. Восемь мобильных маршрутов проверены на тестовых API без ошибок и переполнения.
